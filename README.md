# React Real Estate Website 🏡
A modern **Real Estate web application** built using **React.js** that showcases property listings 
with smooth animations, interactive UI components, and responsive design.

---

🔗 **Live Demo:**  :-- https://real-e-state-react-manaswini-sasmals-projects.vercel.app/

---


## 🚀 Project Overview

This React Real Estate project is designed to simulate a **real-world property listing platform**.  
It focuses on UI/UX, animations, and component-based architecture rather than backend integration.

The project demonstrates:
- Advanced React UI libraries
- Smooth animations
- Reusable and accessible components
- Responsive and modern design patterns

This is a **strong portfolio project** suitable for frontend interviews.

---

## ✨ Key Features

- 🏠 Property listings UI
- 🎞️ Smooth animations using Framer Motion
- 🔢 Animated counters for statistics
- 📂 Accordion sections for FAQs / property details
- 🖱️ Outside click detection for dropdowns
- 🎠 Image sliders using Swiper
- 🎨 Icons using React Icons
- 📱 Fully responsive layout
